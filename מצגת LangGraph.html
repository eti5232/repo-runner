RepoRunner

איך LangGraph עובד, ואיך הלולאה בפרויקט פועלת

סוכן שמריץ פרויקט Python בקונטיינר, מאבחן שגיאות, מתקן, ועוצר לאישור אדם לפני פעולות רגישות

LangGraph ב-5 מושגים

State

מילון משותף (RunState) שכל צומת קורא ממנו וכותב אליו: התוכנית, השגיאה, מספר הניסיונות.

Node (צומת)

פונקציית פייתון רגילה: מקבלת State, מחזירה עדכון. חלק מהצמתים קוראים ל-LLM, רובם לא.

Edge (קשת)

קובעת מי הצומת הבא. קשת רגילה היא קבועה.

Conditional Edge

פונקציית ניתוב (route_after_...) בוחרת צומת לפי ה-State. זה מה שיוצר לולאות וענפים.

interrupt + Checkpointer

interrupt() עוצר את הגרף וממתין לאדם. ה-SqliteSaver שומר את המצב, אז אפשר לסגור ולהמשיך אחר כך.

הרעיון: במקום סקריפט ישר, מתארים את הסוכן כגרף. הלולאות והעצירות הן חלק מהמבנה, לא "טריק" בקוד.

הארכיטקטורה: מי מדבר עם מי

הגרף הוא המוח. הקונטיינר הוא ארגז החול שבו הקוד של הפרויקט באמת רץ. ה-LLM נקרא רק כשצריך שיפוט, ו-LangSmith מתעד כל צעד.

הגרף של RepoRunner

סגול = צמתים שקוראים ל-LLM. כל שאר ההחלטות (בטיחות, ניתוב, הצלחה) הן קוד דטרמיניסטי.

4 הלולאות בגרף

1. לולאת הצעדים

execute_step ← הצליח ויש עוד צעדים ← execute_step. כך עוברים על התקנה, הרצה ובדיקה.

2. לולאת החקירה

diagnose_error ← investigate ← diagnose_error. המודל קורא קבצים עד 5 פעמים, ומסיים כשהוא קורא ל-submit_diagnosis.

3. לולאת התיקון

הרצה ← כשל ← אבחון ← תיקון ← שער בטיחות ← הרצה. נעצרת בהצלחה או ב-MAX_ATTEMPTS = 8.

4. אימות

verify לא עבר ← חזרה ל-diagnose_error. הצלחה נקבעת בהרצה אמיתית, לא בהערכה של המודל.

כל לולאה נשלטת על ידי פונקציית ניתוב שבודקת את ה-State, וכל לולאה יש לה תנאי עצירה, כדי שלא תרוץ לנצח.

דוגמה: חבילה חסרה ב-requirements

  1. plan_run בונה צעדים: pip install -r requirements.txt, ואז הרצת הסקריפט.
  2. execute_step מריץ בקונטיינר. התוצאה: ModuleNotFoundError: numpy.
  3. route_after_execute: נכשל ו-attempts < MAX, ולכן עוברים ל-diagnose_error.
  4. המודל קורא requirements.txt דרך investigate, ומסווג: "חבילה חסרה".
  5. propose_fix מציע pip install numpy ו-echo numpy >> requirements.txt.
  6. safety_gate: הפקודה ברשימת ההיתר, ולכן היא בטוחה ומתווספת לתוכנית.
  7. חוזרים ל-execute_step, הפעם מצליח. verify עובר, ו-report בונה Dockerfile.
